# Security

AI Shopping Assistant is a local deterministic analysis plugin.

It does not:

- make network requests;
- log in to commerce accounts;
- place orders or make payments;
- write user data to disk;
- install dependencies at runtime;
- request passwords, OTP/SMS verification codes, cookies, bank-card data, payment passwords, or payment credentials.

The calling agent is responsible for obtaining current evidence and respecting platform access controls.

Source-quality flags are advisory shopping-research signals, not legal findings about merchants, platforms, brands, reviewers, or publishers.

Security reports should be sent privately to the repository maintainer rather than posted with sensitive details in a public issue.
